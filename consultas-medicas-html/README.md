# Vitalia - versión estática HTML

Esta copia contiene páginas HTML, CSS y JavaScript para mostrar el diseño en GitHub Pages o en cualquier servidor web estático. También puedes abrirla en XAMPP como una demostración visual.

## Publicar en GitHub Pages

1. Sube estos archivos al repositorio de GitHub.
2. En el repositorio, abre **Settings → Pages**.
3. En **Build and deployment**, elige **Deploy from a branch**, selecciona `main` y la carpeta `/ (root)`, y guarda.
4. GitHub mostrará el enlace público cuando termine la publicación. La página de inicio es `index.html`.

## Límites de esta versión

Esta versión es estática. No procesa registros, inicio de sesión, citas, solicitudes de servicio, órdenes médicas, correo ni base de datos. No solicites ni guardes datos reales en este demo. Para esas funciones usa la aplicación PHP original en XAMPP o un hosting que ejecute PHP y MySQL.

Todos los nombres, horarios, correos y datos de contacto que se muestran son demostrativos y deben reemplazarse por información autorizada antes de una presentación pública.
